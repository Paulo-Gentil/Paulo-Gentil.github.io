# Portfólio — Paulo Gentil

Site estático em português, pronto para GitHub Pages. Não precisa de instalação ou compilação.

## Publicar

1. No GitHub, crie o repositório público `Paulo-Gentil.github.io`.
2. Envie o conteúdo desta pasta para a raiz do repositório, na branch `main`. Inclua `index.html`, `styles.css`, `favicon.svg`, `projects.js`, `.nojekyll` e a pasta `assets/`.
3. Em **Settings → Pages**, escolha **Deploy from a branch**, branch **main**, pasta **/ (root)** e salve.
4. Acompanhe a publicação em **Actions**. O endereço será https://paulo-gentil.github.io/.

Se o repositório já existir, confira seu conteúdo antes de enviar os arquivos.

## Editar

- `index.html`: apresentação, descrição dos projetos e links. Para destacar outro projeto, acrescente um elemento `article` seguindo a estrutura do Top Grid e adapte o conteúdo.
- `styles.css`: cores, tipografia e comportamento em telas menores.
- `favicon.svg`: ícone da aba.

O contato aponta para o perfil público do GitHub. Não há formulário, coleta de dados ou dependências externas.

O projeto em destaque usa o logo oficial em `assets/top-grid-logo.svg` e aponta para https://topgrid.app.

As abas separam projetos próprios e projetos para empresas. O painel de empresas está reservado para inclusão posterior. `projects.js` controla as abas com suporte a teclado.
